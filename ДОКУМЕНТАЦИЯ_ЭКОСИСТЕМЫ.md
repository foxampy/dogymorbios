# Документация экосистемы DOGYmorbis World 🐕

## Обзор

DOGYmorbis World — комплексная цифровая экосистема для владельцев собак с уникальным игровым интерфейсом в стиле "Plush UI". Приложение объединяет уход за питомцем, социальное взаимодействие, ветеринарный контроль и игровую механику с внутренней экономикой.

---

## 1. Основные модули экосистемы

### 1.1. Модуль онбординга (Onboarding)
**Назначение:** Первичная настройка профиля пользователя и питомца

**Функции:**
- Регистрация имени владельца
- Создание профиля собаки (имя, порода, дата рождения)
- Настройка аватара питомца (выбор породы, цвета шерсти, размера)
- Выбор характеристик личности (до 5 тегов)
- Выдача стартового бонуса: 50 костей

**Компоненты:**
- `BreedSelector` — выбор породы из каталога
- `AvatarCreator` — создание визуального аватара
- `PersonalitySelector` — выбор черт характера

---

### 1.2. Модуль главной страницы (Home/Kennel)
**Назначение:** Центральная панель управления и мониторинга состояния питомца

**Функции:**
- Отображение статуса питомца (голод, энергия, настроение)
- Быстрые действия (кормление, игра, прогулка)
- Виджет погоды
- Статистика активности
- Система достижений
- Кнопка быстрого старта прогулки

**Компоненты:**
- `PetStatusWidget` — индикаторы состояния питомца
- `QuickActions` — панель быстрых действий
- `WeatherWidget` — информация о погоде
- `StatsWidget` — статистика пользователя
- `WalkButton` — кнопка начала прогулки

---

### 1.3. Модуль территории (Territory)
**Назначение:** Интерактивная карта для отслеживания прогулок и исследования мест

**Функции:**
- Трекинг прогулок в реальном времени
- Отображение маршрута на карте
- Запись времени и расстояния прогулки
- Отслеживание встреч с другими собаками
- Список интересных мест
- Начисление костей за прогулки

**Механика начисления:**
- За каждые 0.1 км пройденного расстояния начисляется 1 кость
- Формула: `кости = расстояние × 10`

**Компоненты:**
- `MapView` — интерактивная карта
- `WalkTracker` — трекер активной прогулки
- `PlacesList` — список мест поблизости

---

### 1.4. Модуль социальной сети (Pack)
**Назначение:** Социальное взаимодействие между владельцами собак

**Функции:**
- **Лента новостей:** просмотр постов других пользователей
  - Лайки и комментарии
  - Публикация фотографий
  - Взаимодействие с контентом
  
- **Sniff (Поиск друзей):** Tinder-подобный интерфейс для поиска друзей для игр
  - Просмотр профилей собак поблизости
  - Лайк/Пропуск профилей
  - Информация о породе, возрасте, характере
  
- **Чаты:** система сообщений (в разработке)

**Компоненты:**
- `PostCard` — карточка поста в ленте
- `SniffCard` — карточка профиля для поиска друзей

---

### 1.5. Модуль ветеринарного ухода (Vet Care)
**Назначение:** Управление здоровьем и медицинскими данными питомца

**Функции:**
- **Цифровой паспорт:**
  - Хранение медицинских документов
  - История вакцинаций
  - Записи о посещениях ветеринара
  
- **Напоминания о вакцинации:**
  - Уведомления о предстоящих прививках
  - Отметка о выполненных вакцинациях
  - Отслеживание просроченных прививок
  
- **Трекер здоровья:**
  - Запись веса питомца
  - Отслеживание настроения
  - Заметки о состоянии здоровья
  
- **AI Ветеринар:** чат-бот для консультаций (в разработке)

**Компоненты:**
- `DigitalPassport` — цифровой паспорт
- `VaccinationReminders` — напоминания о вакцинации
- `HealthTracker` — трекер здоровья
- `AIVetChat` — AI-консультант

---

### 1.6. Модуль магазина (Treat Shop)
**Назначение:** Внутренний магазин для покупки товаров за игровую валюту

**Функции:**
- Каталог товаров (корм, игрушки, аксессуары, средства ухода)
- Поиск и фильтрация по категориям
- Корзина покупок
- Система скидок
- Покупка товаров за кости

**Категории товаров:**
- 🍖 Корм
- 🎾 Игрушки
- 👔 Аксессуары
- 🧴 Средства ухода

**Компоненты:**
- `ProductCard` — карточка товара
- `Cart` — корзина покупок

---

### 1.7. Модуль профиля (Profile)
**Назначение:** Управление профилем пользователя и просмотр статистики

**Функции:**
- Редактирование профиля владельца и питомца
- Просмотр статистики активности
- Система достижений
- Настройки приложения
- Выход из аккаунта

**Статистика:**
- Общее количество прогулок
- Пройденное расстояние
- Дни подряд (streak)
- Заработанные кости
- Количество достижений

**Компоненты:**
- `ProfileHeader` — заголовок профиля
- `StatsOverview` — обзор статистики
- `SettingsList` — список настроек

## 5. Экономика костей (Косточкономика) 🦴

### 5.1. Внутренняя валюта: Кости (Bones)
Кости — основная валюта экосистемы DOGYmorbis, используемая для покупки товаров и услуг.

### 5.2. Способы заработка костей

#### 5.2.1. Прогулки
- **Механика:** За каждые 0.1 км пройденного расстояния начисляется 1 кость
- **Формула:** `кости = расстояние × 10`
- **Пример:** Прогулка на 2.5 км = 25 костей

#### 5.2.2. Публикация фото
- **Награда:** +5 костей за каждую опубликованную фотографию в ленте Pack

#### 5.2.3. Ежедневный вход
- **Награда:** +3 кости за ежедневный вход в приложение
- **Механика:** Начисляется один раз в день при первом открытии приложения

#### 5.2.4. Стартовый бонус
- **Награда:** 50 костей при завершении онбординга

### 5.3. Трата костей

#### 5.3.1. Магазин товаров
Товары можно приобрести за кости в разделе "Магазин лакомств":

**Категории и примеры цен:**
- **Корм:** от 35 до 70 костей
- **Игрушки:** от 15 до 30 костей
- **Аксессуары:** от 80 до 100 костей
- **Средства ухода:** от 25 костей

#### 5.3.2. Система скидок
- Некоторые товары имеют скидки (до 29%)
- Отображается оригинальная и акционная цена

### 5.4. Баланс костей
- Хранится в `useUserStore` (Zustand)
- Сохраняется в localStorage через persist middleware
- Минимальный баланс: 0 (не может быть отрицательным)

### 5.5. Экономический баланс
Система спроектирована так, чтобы:
- Поощрять активность (прогулки, публикации)
- Создавать мотивацию для ежедневного использования
- Обеспечивать баланс между заработком и тратами

## 6. Юнити экономика (Unity Economy)

### 6.1. Концепция
Юнити экономика — потенциальная система единиц измерения прогресса и достижений в экосистеме DOGYmorbis. Может включать:

### 6.2. Возможные механики

#### 6.2.1. Единицы опыта (Experience Units)
- Начисление за различные действия
- Прокачка уровня питомца
- Разблокировка новых функций

#### 6.2.2. Единицы репутации (Reputation Units)
- Социальная репутация в сообществе Pack
- Влияние на видимость в ленте
- Доступ к эксклюзивным функциям

#### 6.2.3. Единицы здоровья (Health Units)
- Количественная оценка состояния питомца
- Интеграция с модулем Vet Care
- Влияние на игровой процесс

### 6.3. Интеграция с косточкономикой
Юнити экономика может работать параллельно с системой костей:
- Кости — для покупок и транзакций
- Юнити — для прогресса и достижений

**Примечание:** На текущий момент юнити экономика находится в стадии концептуализации и может быть реализована в будущих версиях приложения.

```typescript
{
  id: string
  humanName: string
  dogs: Dog[]
  bonesBalance: number
}
```

### 7.2. Модель собаки (Dog)
```typescript
{
  name: string
  breed: string
  birthdate?: string
  personalityTags: string[]
  avatarConfig: {
    breed: DogBreed | null
    furColor: string
    noseColor: string
    size: 'small' | 'medium' | 'large'

}
```

### 7.3. Модель прогулки (Walk)
```typescript
{
  id: string
  startTime: Date
  path: Array<{ lat: number; lng: number }>
  poops: number

}
```

{
  id: string

  description: string
  price: number
  originalPrice?: number
  discount?: number
  rating?: number

  category: 'food' | 'toys' | 'accessories' | 'care'
